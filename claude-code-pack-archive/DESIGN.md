# DESIGN.md — дизайн-система «Современный город»

Источник истины — `design/reference/*.html`. Этот файл описывает правила, по которым они сделаны.

## 1. Характер
Инженерный, спокойный, взрослый. Графитовые поверхности, бетонный серый, белый текст. Нет декора ради декора: каждая линия, цвет и размер что-то значат. Тон текста: коротко, по делу, на «вы».

## 2. Токены (CSS-переменные)
```css
:root{
  --bg:#F2F2F0; --card:#FFFFFF; --ink:#16191B; --mut:#6B7073;
  --line:rgba(22,25,27,.16); --slot:#D6D6D3;
  --dk:#16191B; --dki:#EFEFED; --dkm:#8E9497; --dkl:rgba(239,239,237,.18);
  --amber:#FFB000; --ok:#3E7C5A;
  --gx:max(clamp(16px,3.2vw,44px),env(safe-area-inset-left),env(safe-area-inset-right));
  --ease:cubic-bezier(.7,0,.2,1);
}
```
- `--gx` — боковое поле страницы. Все блоки используют его, ничего не центрируем «на глаз».
- Тёмные страницы (события, новости, ЖК, детальные) включаются классом `#sg.pg`: `--ink:var(--dki); --mut:var(--dkm); --line:var(--dkl); --bg:var(--dk); --slot:#2B2F32`, `html,body{background:var(--dk)}`.
- Новости (деталь): hero чуть светлее фона, `#242A2D`, тег `rgba(239,239,237,.12)`. Только оттенок серого, без цвета.
- Янтарь — только плашка отключений. Зелёный `--ok` — статус «штатно».

## 3. Типографика
Шрифты: **Onest** (весь интерфейс), **Golos Text** только для подзаголовков секций и заголовков пустых состояний. Один шрифт на странице в основном тексте.
| Роль | Размер | Вес | Трекинг | Интерлиньяж |
|---|---|---|---|---|
| H1 главной (hero) | как в `index.html` | 300 | −.055em | .94 |
| H1 внутренних страниц | `clamp(34px,4.6vw,78px)` | 300 | −.055em | 1 |
| H2 секции / месяца | `clamp(24px,2.3vw,36px)`, Golos Text | 400 | −.04em | 1 |
| Дата на детальной события | `clamp(56px,6.4vw,104px)` | 300 | −.06em | .9 |
| Заголовок карточки | `clamp(17px,1.45vw,21px)` | 300 | −.03em | 1.15 |
| Лид | `clamp(16px,1.35vw,20px)` | 300 | 0 | 1.4 |
| Текст | 15–16px | 300–400 | 0 | 1.45 |
| Подпись (eyebrow, мета) | 12–13px | 400 | .01em | — |
Правила: не делать гигантские размеры (заказчик дважды просил уменьшать), не больше трёх размеров в одном блоке, серый (`--mut`) для второстепенного, не для основного. Неразрывный пробел после коротких слов: `/(?<=^|[\s(«„—–-])([A-Za-zА-Яа-яЁё]{1,3})\s+(?=\S)/g` → `$1 `.

## 4. Сетка и ритм
- Поля `--gx`, внутри без вложенных контейнеров с max-width, кроме текстовых колонок (`44em`, `1200px` для фильтров).
- Отступы блоков по вертикали: `clamp(72px,9vw,128px)` внизу страницы, `clamp(40px,5vw,72px)` между шапкой страницы и списком.
- Сетка карточек: 4 колонки, `gap:12px`; ≤1400px — 3; ≤1000px — 2; ≤560px — 1 (`gap:10px`).
- Брейкпоинты: 1400, 1000, 900 (меню), 560/520 (мобильный).
- Соседние блоки не повторяют друг друга по форме: если выше сетка фото-карточек, ниже текстовые карточки или список.

## 5. Линии и рамки
Линия — осознанный приём, как в статистике hero главной: горизонтальная линия от левого края экрана до правого + вертикальная от неё вниз. Использовать только в hero-рамке. В фильтрах, списках, карточках линий не добавлять (заказчик: «колоссальное количество линий»). Линия `rgba(239,239,237,.3)`, 1px.

## 6. Компоненты
**Шапка / меню / линейка / подвал** — каркас из `index.html`. Пункты: Объекты, Мероприятия, Новости, Документы, О компании, Контакты. Линейка внизу заполняется по скроллу, шапка получает `.scrolled` после 60px, над подвалом `inv-top`/`inv-bot`.

**Кнопка `.btn`** — прямоугольник: текст на `--ink`, справа квадрат 52×52 со стрелкой на `--slot`; на hover квадрат заливается, стрелка поворачивается на 45°. Высота 52px. Скругление нет.

**Фильтр-плашка `.pill`** — прямоугольник 52px, `padding:0 22px`, фон `--slot`, счётчик `<sup>` справа. Активная: фон `--dki`, текст `--dk`. Сброс фильтра — `.reset` с рамкой. Состояние в URL: `?zhk=<id>`.

**Карточка мероприятия `.card`** — 4:5, фото на весь фон (`brightness(.78)`), градиент сверху/снизу, сверху тип и ЖК, снизу крупная дата, название (до 15ch), время; стрелка в круге справа внизу. «Все мероприятия» — тёмная плитка-сетка без фото. Прошедшие — десатурированные.

**Карточка новости `.nc`** — текстовая, фон `--slot`, дата, тег ЖК, заголовок, лид; hover — светлая заливка. Главная: большая новость (span 7, 2 строки, серая) + малые (span 5, светлые).

**Тег ЖК `.etag` / `.tg`** — прямоугольник 12px, `padding:5px 11px`, фон `color-mix(currentColor 11%, transparent)`. Без скругления. (Тег на фото-карточке сейчас с рамкой-капсулой, при правках приводи к прямоугольнику.)

**Hero детальной страницы события `.ehero`** — фото на весь экран `min-height:max(560px,86vh)`, градиент, тег, крупная дата, H1, колонка фактов (Когда / Где / Для кого), кнопки «Добавить в календарь» (.ics) и «Поделиться».

**Hero страницы ЖК `.zhero`** — фото ЖК на весь экран, слева тег «Жилой комплекс» и название ЖК (`H1`), справа рамка-поле: «Район» (значение 18–22px, вес 400) и «Адреса» (улица + номера домов одной строкой «ул. Тракторостроителей 21, 21/1, 21/2», белым, 15–18px, вес 400). Рамка из двух линий: горизонтальная до обоих краёв экрана и вертикальная слева. Последняя строка адресов стоит на базовой линии названия ЖК (выравнивает JS, сдвигая только текст, не линии); расстояние от горизонтальной линии до подписи «Район» равно расстоянию от последней строки до низа hero. Мобильный: рамка без линий, блок под названием.

**Пустое состояние `.empty`** — заголовок Golos Text, одно предложение, две кнопки: сбросить фильтр и перейти в общий список.

**Блок на странице ЖК** — «Мероприятия ЖК» (до 4 ближайших + плитка «Все») и «Новости ЖК» (3 последних). Если данных нет — спокойное пустое состояние `.none`, блок не исчезает.

## 7. Страницы
| Страница | Файл | Роль |
|---|---|---|
| Главная | `index.html` | Сценарий «срочно позвонить», принцип, список ЖК, мероприятия, новости, документы |
| Мероприятия | `events.html` | Заголовок, фильтр-плашки по ЖК, группы по месяцам, карточки |
| Новости | `news.html` | Тот же каркас, 3 колонки текстовых карточек |
| Мероприятие | `event.html?id=` | Hero-фото, факты, текст, календарь, другие мероприятия |
| Новость | `news-item.html?id=` | Hero `#242A2D`, «Касается» (ЖК), текст, файлы `.file`, другие новости |
| ЖК | `zhk.html?id=` | Hero с названием, районом и адресами; мероприятия и новости этого ЖК |
Внутренние страницы читаются как одна система: те же шапка, линейка, подвал, `.btn`, `--gx`.

## 8. Данные
- Новость: `{date, complex, title, text}`. `complex: 'all'` — для всех ЖК.
- Мероприятие: `{date, z, t, time, place}`. `z: 'all'` показывается под любым фильтром.
- ЖК: `{id, n, ad:[[улица,[дома]]], district}`.
- ID ЖК: `geroi, novy, semeyny, severny, bereg, zenit, granat, tarifnaya, gvard35 («На 35‑й Гвардейской»), atlasova`. Район пока известен только у `novy` (Тракторозаводский район); у остальных поле скрыто, пока нет данных.
- В репозитории новости идут из `news.json`/Payload (`web/src/collections/News.ts`); поле `complex` нужно добавить в коллекцию и в `admin.html`.

## 9. Состояния и поведение
Hover кнопок и карточек 0.3–0.45s `var(--ease)`; фото карточек `scale(1.05)` за 1.1s. Фокус: `outline:2px solid var(--ink); outline-offset:3px`. `prefers-reduced-motion`: без пина, дуги и параллакса. Фильтр не перезагружает страницу, обновляет URL. Загрузка картинок — `loading="lazy"`, у hero нет.

## 10. Мобильная версия
Меню скрыто ≤900px (бургер). Сетки перестраиваются по брейкпоинтам выше. Телефон диспетчерской виден всегда (на мобильном — нижняя панель). Горизонтального скролла нет ни на одной странице. Touch-цели ≥44px.

## 11. Чего не делать
Гигантские заголовки; пилюли и скруглённые кнопки; тени и стеклянные эффекты ради эффекта; радужные акценты; иконки-стикеры; много линий; служебные подписи; повторять блок рядом с таким же; светлый цветной hero у новостей; выделять отдельные дома; писать название застройщика.
